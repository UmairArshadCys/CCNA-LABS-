# Spanning Tree Protocol

This folder contains Packet Tracer labs for practicing **Spanning Tree Protocol (STP)** and understanding how STP prevents Layer 2 loops.

It includes:

* **Find the Root Bridge** — Identify the Root Bridge and determine the Root, Designated, and Non-Designated/Alternate port roles.
* **STP Configuration** — Configure and verify STP settings on switches using the CLI.

Use the Packet Tracer files to practice each topology yourself before checking the CLI output and configurations.
