# NAT Configuration

### Overview

This folder contains Cisco Packet Tracer labs for configuring and troubleshooting **Network Address Translation (NAT)**.

### Configurations

* **Static NAT** – Maps private IP addresses to specific public IP addresses.
* **Dynamic NAT** – Maps private IP addresses to available public IP addresses from a configured pool.

### Outcome

Practiced configuring NAT on Cisco routers and verifying NAT translations using Packet Tracer.
